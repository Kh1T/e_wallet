# =========================================================
# HOW IT WORKS
# =========================================================

1. Customer logs in and pays a bill:
   - Select Category (e.g., Electricity)
   - Select Biller (e.g., Electricite du Cambodge)
   - Enter Amount
   - Confirm with PIN

2. System transfers money:
   - Deducts from customer wallet
   - Credits biller's wallet (if biller has a user account)
   - Creates transaction records for both

3. Biller can log in to check:
   - Go to "Accounts" to see wallet balance
   - Go to "Transactions" to see payment history
   - View "Bill Payment Received" transactions

4. Admin can check in Django Admin:
   - Go to /admin/wallet/biller/
   - See "Wallet Balance" column showing biller's credit
